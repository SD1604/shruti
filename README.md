# Shruti — Multi-Agent RAG System for Vedic Scripture

A citation-grounded Retrieval-Augmented Generation (RAG) system that answers
questions using ancient Indian scriptures — starting with the Bhagavad Gita,
built to scale to the Vedas, Upanishads, Mahabharata, and Ramayana.

Built with **LangGraph** (multi-agent orchestration), a custom **MCP server**
(retrieval layer), **FastAPI** (backend), and **React** (frontend).

## Why this exists

Most "scripture chatbots" let an LLM paraphrase from memory, which risks
misquoting or inventing content. This system instead retrieves the actual
verse from a vector database first, and a validator agent checks that every
claim in the final answer traces back to a real retrieved verse before it's
shown to the user.

## Project structure

```
vedic-copilot/
├── data/
│   ├── raw/                 # scraped source files (gitignored, regenerate locally)
│   └── ingestion/           # fetch, parse, validate, embed scripts
├── schemas/
│   └── verse.py             # shared Pydantic contract for every verse
├── mcp_server/               # Phase 2 — retrieval exposed as MCP tools
├── agent/                    # Phase 3 — LangGraph orchestration
├── backend/                  # Phase 4 — FastAPI app
├── frontend/                  # Phase 5 — React chat UI
├── tests/
├── vector_store/              # gitignored, generated by running ingestion
├── requirements.txt
└── .env.example
```

## Setup

```bash
git clone https://github.com/<your-username>/shruti.git
cd shruti
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # then fill in your own API keys
```

## Running the Gita ingestion pipeline (Phase 1)

```bash
cd data/ingestion
python fetch_gita.py          # ~3-4 min — pulls Sanskrit + transliteration
python fetch_translation.py   # ~15 sec  — pulls public domain English translation
python embed_and_load.py      # parses, validates, embeds, and loads into vector_store/
```

## Data sources and licensing

| Source | Content | License |

| [vedicscriptures.github.io](https://vedicscriptures.github.io) | Sanskrit + transliteration only | Public domain (ancient text) |
| [sacred-texts.com](https://sacred-texts.com/hin/sbg/) | English translation, Swami Swarupananda (1909) | Public Domain / Creative Commons |

This project deliberately excludes modern copyrighted translations (e.g.
Gita Press, ISKCON/Prabhupada, Swami Nikhilananda editions) from its ingested
corpus to keep the codebase safely open-source.

## Tech stack

- **Generation:** Qwen3-30B-A3B-Instruct via Groq (free tier)
- **Embeddings:** Qwen3-Embedding-0.6B, run locally via `sentence-transformers`
- **Vector store:** Chroma
- **Orchestration:** LangGraph
- **Retrieval layer:** custom MCP server
- **Backend:** FastAPI
- **Frontend:** React
